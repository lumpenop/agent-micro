LOCAL GIT · OPTIONAL GITHUB

로컬 Git은 바로.
GitHub는 필요할 때 연결.

Mac의 로컬 Git은 곧바로 사용하고, GitHub는 첫 실행이나 Settings에서 선택적으로 연결하세요. 작업 중에는 변경 파일 확인부터 스테이징, Pull·Push, 커밋까지 앱 안에서 처리할 수 있습니다.

  • 01 첫 실행에서 기존 GitHub 로그인 자동 확인
  • 02 브랜치와 변경 파일, 스테이징 상태 확인
  • 03 파일별 또는 전체 스테이징과 되돌리기
  • 04 Pull·Push와 커밋 메시지 자동 생성
  • 05 충돌하거나 겹치는 파일의 병합 방지
