LOCAL GIT · OPTIONAL GITHUB

로컬 Git은 바로.
GitHub는 필요할 때 연결.

Mac의 로컬 Git은 곧바로 사용하고, GitHub는 첫 실행이나 Settings에서 선택적으로 연결하세요. 작업 중에는 변경 파일 확인부터 스테이징, Pull·Push, 커밋까지 앱 안에서 처리할 수 있습니다.

  1. 첫 실행에서 기존 GitHub 로그인 자동 확인
  2. 브랜치와 변경 파일, 스테이징 상태 확인
  3. 파일별 또는 전체 스테이징과 되돌리기
  4. Pull·Push와 커밋 메시지 자동 생성
  5. 충돌하거나 겹치는 파일의 병합 방지

WHEN ONE AGENT ISN'T ENOUGH

큰 작업에는 여섯 에이전트를.
각자의 작업은 깔끔하게.

혼자 처리하기 벅찬 작업은 여러 에이전트에 나눠 맡기세요. 1번 에이전트는 main을 지키고, 나머지는 서로 분리된 작업 공간에서 안전하게 실행됩니다.

02

03
순서에 맞춘 병합
