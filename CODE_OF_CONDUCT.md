# Code of Conduct

Agent Micro is a collaborative open-source project. We want participation to be welcoming, respectful, and useful.

Expected behavior:

- Be respectful and constructive.
- Assume good intent and ask for clarification before making personal judgments.
- Focus feedback on the code, design, documentation, or idea—not the person.
- Make space for different experience levels and backgrounds.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, sexualized language, doxxing, and deliberately disruptive conduct.

Project maintainers may remove comments, close issues, or reject contributions that violate this code. To report a concern, contact the repository maintainers privately through the contact method listed on the GitHub profile.
