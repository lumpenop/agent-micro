# Agent Micro Roadmap

This roadmap is directional, not a promise of dates. Ideas and pull requests are welcome.

## Now

- Stabilize the macOS first-run flow
- Improve Codex connection and project-folder errors
- Add more onboarding and accessibility polish
- Document common setup and permission problems

## Next

- Signed and notarized macOS distribution
- Automated UI smoke tests
- More reliable terminal-session recovery
- Homebrew Cask distribution
- Better release notes and upgrade handling

## Community projects

- Windows Terminal and PowerShell support
- Linux terminal support
- More language translations
- Keyboard navigation and VoiceOver improvements
- Additional integrations and customizable actions

## Not currently planned

- Providing an AI model inside Agent Micro
- Replacing Codex CLI or the user's terminal
- Uploading voice recordings to a remote transcription service

Open an Issue before starting a large roadmap change so the approach can be aligned with the project direction.
