Codex CLI 설정

Codex CLI 동작 · 저장 시 ~/.codex 에 반영되고 새 CLI 창부터 적용됩니다.

CLI가 파일/시스템에 쓸 수 있는 범위입니다. read-only는 안전하고, workspace-write는 프로젝트 안에서만 수정, danger-full-access는 제한이 거의 없습니다.

명령 실행 전에 사용자 확인을 받을지 정합니다. untrusted가 가장 까다롭고, never는 자동 실행에 가깝습니다.

MCP 서버가 뜰 때까지 기다리는 시간. 기본 10초 · 무거운 서버면 30–60 권장.

도구 한 번 호출의 제한 시간. 기본 60초 · 긴 작업이면 늘리세요.

agents.job_max_runtime_seconds · 한 작업(Job)이 너무 오래 돌면 끊습니다. 기본 1800초(30분) 전후.

features.network_proxy · 모델의 외부 네트워크 요청을 프록시로 세밀하게 제어합니다. 불필요한 외부 호출을 줄일 때 켭니다.

.codexignore — RAM/컨텍스트 절약용. node_modules·빌드 산출물 등 불필요 파일을 제외하는 샘플을 프로젝트 폴더에 만듭니다.
config.toml — ~/.codex/config.toml 을 열어 직접 확인·수정합니다.
